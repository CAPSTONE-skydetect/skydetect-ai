# C 전달 시뮬레이터 1.4.0과 현재 1.6.0 비교

2026-10-05. 기존 C 전달 ZIP의 `sequence-guidance-1.4.0` 산출물과
현재 `sequence-guidance-1.6.0`의 50~500m 카메라 범위를 비교했다.
두 자료의 입력 계약은 모두 `trajectory-sequence-1.0.1`이다.

## 비교 조건

기존 전달 실험의 실제 A train/validation 분할, 2초 창 지표,
정규화 척도, 행동 guidance 및 합성 비행 시드를 그대로 썼다.
1.4.0의 저장된 프로필에는 거리 범위 필드가 없으므로 당시 설정인
20~1500m를 명시적으로 복원했다. 같은 시드로 생성한 잠재 3D 비행과
과거 카메라 조건의 광학 관측·A 유사 추적 history가 **train 120비행과
validation 48비행 모두에서 저장된 1.4.0 기록과 일치**하는지 확인했다.
그 뒤 잠재 비행과 나머지 관측 설정을 유지하고 카메라 범위만
50~500m로 변경했다. 실제 test는 열지 않았다.

분포 거리는 실제 A와 합성 2초 창의 투영·형태·시간 지표별 Wasserstein
거리를 실제 train의 척도로 정규화해 새/드론과 범주에 동일 가중 평균한
수치다. 낮을수록 가깝지만 정확도도, 0~1 척도도 아니다.
MMD²는 전체 4채널 시계열 형태의 보조 거리이며 역시 낮을수록 가깝다.

## 같은 비행의 결과

| 자료·지표 | 전달 1.4.0, 20~1500m | 현재 1.6.0, 50~500m | 해석 |
|---|---:|---:|---|
| 합성 train 대 실제 train 분포 거리 | 0.8837 | **0.8435** | 개선 |
| 실제 validation 분포 거리 | **0.9036** | 0.9130 | 소폭 악화 |
| train 유효 비행 | 104/120 | **107/120** | 3비행 증가 |
| validation 유효 비행 | 45/48 | 45/48 | 동일 |
| validation 새 시계열 MMD² | 0.12129 | **0.11928** | 소폭 개선 |
| validation 드론 시계열 MMD² | 0.02993 | 0.02993 | 사실상 동일 |

validation에서 새의 2초 화면 이동 폭 중앙값은 실제 0.171,
두 합성 모두 약 0.197이다. 중앙값이 비슷해도 분포의 꼬리와
회전·저이동 같은 다른 지표에서 차이가 생긴다. 실제로 새의 평균
방향 전환 지표 `turn_radians_mean`은 실제 중앙값 약 0.242,
합성 약 0.075로 여전히 부족하다. 드론 validation 지표는 거의 변하지
않았다. **카메라 범위 제한만으로 행동·시간 구조의 불일치를 해결하지
못했다.**

앞선 `CAMERA_RANGE_V2_AUDIT_20261005.md`의 validation
`1.145 → 1.065`는 **다른 합성 시드 351000, 클래스당 12비행**의 결과다.
여기서는 전달 ZIP과 정확히 비교하기 위해 **원래 시드 121000,
클래스당 24비행**을 사용했다. 서로 다른 두 숫자를 버전 개선의
확정적 증거로 합치면 안 된다. 서로 다른 시드에서 결과 방향이
달라진 것은 현재 소규모 시뮬레이션 평가의 민감성을 보여준다.

기존 1.4.0의 C 모델에서는 합성 혼합이 실제 validation 영상 그룹
macro-F1을 `real-only 0.899`에서 `real+synthetic 0.697`로 낮췄다.
**1.6.0 합성으로 C 모델을 재학습한 성능은 아직 측정하지 않았다.**
따라서 이 표는 1.6.0이 C 학습 성능을 높였다는 주장도, 합성 데이터를
기본 학습에 넣어도 된다는 승인도 아니다. 기존 C ZIP은 변경하지 않았다.

실행 산출물: `output/paired_1p4_vs_1p6_20261005/`의 `result.json`,
분할별 `*_metrics_comparison.csv`, 재생 프로토콜.
같은 train cohort의 비교 그림은 하위 `figures/`에 있다.
`trajectory_examples_1p6.png`는 클래스·도메인별 2초 화면 이동 폭의
중앙에 가까운 창을 골라 실제 화면 비율과 형상 정규화 좌표로 그린다.
화면 패널은 비교를 위해 중심 이동했으므로 원본 프레임 내 위치가 아니다.
`screen_span_medians_1p6.png`는 영상/비행 그룹 가중 중앙값이다.
실제 A 대 1.6.0 합성은 새 **27.79% 대 15.64%**, 드론 **5.46% 대
11.98%**다. 1.4.0 합성의 15.99%와 12.54%에 비해 약간 변했지만,
두 클래스의 화면 이동 폭 차이가 해결됐다고 볼 수준은 아니다.
