2026-10-18 후속 실행 결과와 남은 데이터 요구사항은
[followup_execution_20261018.md](followup_execution_20261018.md)에 기록했다.
아래의 drone_3 채점 차단은 해소되었으며, N4/N4_native/N5 추가 실험도 완료했다.

## 현재 판단

D0를 기준선으로 유지한다. A에서는 측정 좌표 생성 경로를 분해하고, C에서는 같은
실제 학습 자료로 모델을 비교한다. 기존 실험에서 채택 조건을 충족하지 못한 KF/RTS,
원본 해상도 단순 전환, 재획득 지연을 기본값으로 도입하지 않는다.

## 이전 설명 정정과 비교 한계

- D0의 `gt_full`은 XML 전체 길이가 아니라 A의 attempted 평가 구간 안의 모든 GT다.
  `gt_matched`는 그중 A가 관측한 프레임만 남긴 GT다. 여섯 객체 중 네 객체에서는
  두 GT 파일의 프레임과 개수가 같다. 18개 입력을 실행했지만 독립 표본은 18개가 아니다.
- RF는 최대 확률 0.6 미만에서 uncertain을 내고 MiniRocket 기본 임계값은 0이다.
  보류 포함 서비스 결과와 강제 이진 분류 결과를 따로 보고해야 한다.
- 저장된 RF 기여도의 합으로 복원한 GT matched drone 확률 기준으로 강제 이진 판정을
  하면 2/6이다. 서비스 기본 정책에서는 1/6이다. MiniRocket GT matched는 4/6이다.
- RF 모델 provenance는 simulator_version=4.0.0이다. 저장소 train CSV도 합성 자료다.
  MiniRocket 번들은 real_only, train_groups=29, train_windows=156이다.
  지금 결과는 알고리즘, 입력 표현, 학습 자료, 보류 정책이 함께 다른 배포 구성 비교다.
- MiniRocket은 production HTTP 라우터가 아니라 브랜치의 research.predict_track으로
  실행했다. 기본 창 전처리와 margin 평균은 서비스 코드와 일치하지만 API 전체를
  검증한 결과는 아니다. 다음 실험은 production classifier의 결과 일치도 확인한다.
- GT도 사람의 bbox와 같은 A 추정 CMC를 사용한다. GT 입력은 독립적인 물리 운동의
  완전한 정답이 아니며, CMC 오류가 양쪽에 공통으로 들어갈 수 있다.

## 문헌에서 채택할 원리와 적용 한계

1. Liu et al., Remote Sensing 2022, 14, 777, DOI 10.3390/rs14030777:
   KCF 다중 특징, subpixel peak, adaptive KF를 위성 영상에 적용했다.
   측정 위치의 정밀화와 관측 불확실성 처리는 참고할 수 있다. 우리 KLT는 이미
   부동소수점 위치를 쓰므로 appearance peak 정밀화만으로 주 경로 오류를 고치지는 못한다.
2. Lu et al., OITrack, Remote Sensing 2025, 17, 2042, DOI 10.3390/rs17122042:
   LSTM trajectory completion, adaptive KF, 확대 IoU 연관으로 위성 다중 객체를 추적한다.
   재등장 연관과 검색 범위 조절을 참고하되 예측 보간을 관측으로 B에 넘기지 않는다.
   논문도 completion의 false positive 증가 가능성을 명시한다.
3. Pang et al., Sensors 2026, 26, 4639, DOI 10.3390/s26144639:
   작은 객체 특징 보존과 시공간 메모리가 핵심이다. 현재 작은 표본으로 네트워크 전체를
   재학습하기보다 native ROI와 정렬된 단기 영상 증거의 가설을 분리해 검증한다.
   해당 논문의 MOTA/MOTP 개선을 우리 중심점 미분 오차 개선으로 해석하지 않는다.
4. Tong et al., Sensors 2026, 26, 2528, DOI 10.3390/s26082528:
   레이더 15차원 궤적, TCN-Transformer, PC-TimeGAN을 사용한다.
   시계열 표현과 실제 자료를 통한 증강 검증은 참고하되 영상의 2D 픽셀 운동을
   동일한 물리량으로 취급하지 않는다. GAN 확대는 실제 데이터와 분리 검증 후 검토한다.

## 실험 1: 평가 및 학습 출처 확정

- C 담당자의 source inventory와 train/validation/test 분할, 모델-패키지 해시 대응을 확보한다.
- 동일 영상의 객체와 창, GT/A 쌍, 증강 파생물을 같은 그룹에 넣는다.
- 현재 네 영상은 개발 자료로 고정한다. 미사용 원본 영상 그룹을 최종 평가용으로 확보한다.
- 단일 새 영상에서 새 객체 2개가 나온 구성이라는 한계를 결과에 명시한다.
- RF/MiniRocket 기본 서비스 결과와 보류율을 보고하고, 강제 이진 분류도 별도 표시한다.
  동일 coverage 비교의 임계값은 개발 자료에서만 선택한다.

## 실험 2: A의 대비 중심 보정 제거와 제한

현재 manual_roi_tracker는 KLT 변위 중앙값으로 중심을 갱신한 뒤, 주변 영상과 Gaussian
blur의 차이가 최대인 위치로 15% 끌어당긴다. 이 위치가 객체 중심이라는 보장은 없다.
이는 코드로 확인한 원인 후보이며 실제 오류의 원인으로 확정된 것은 아니다.

- N0: D0 그대로.
- N1: KLT 이후 contrast recentering만 끈다.
- N2: 영상의 표적 내부 공간 일관성과 매칭 신뢰도를 만족할 때만 중심 보정을 적용한다.
- E2c는 peak 위치를 subpixel로 바꾼 실험으로, N1과 다르다.
- KLT-only center, correction vector, 최종 center, FB 오차, source 전환을 기록한다.
- 같은 ROI/프레임/CMC 조건에서 위치 Median/P95, 객체 크기 대비 오차, temporal error,
  source별 오류, 관측률, B 특징 차이를 비교한다. 최종 C 라벨로 N1/N2를 선택하지 않는다.

## 실험 3: CMC와 GT 불확실성 분리

- 원본 영상 좌표에서 A-GT 위치/변위 오류를 먼저 측정한다.
- 같은 변환으로 보정한 A/GT 결과를 함께 보여주되 공통 CMC 오류를 검출했다고 주장하지 않는다.
- 객체를 제외한 정적 배경 검증점의 잔차, inlier 공간 분포, 변환 급변을 평가한다.
- 카메라 보정 실패 시 품질 경고를 전달하고 임의 보정값을 신뢰 가능한 물리량으로 쓰지 않는다.
- 문제가 큰 짧은 구간은 두 사람이 독립적으로 다시 라벨링해 GT 중심 변동의 범위를 확인한다.
- B 필터 경계/누락 경계/구간 내부를 따로 보고 전체 구간 결과도 유지한다.
  B acceleration은 속력 변화량이므로 벡터 가속도와 구분한다.

## 실험 4: 같은 실제 자료로 RF와 MiniRocket 재비교

- 동일한 실제 원본 그룹 분할과 동일 관측 구간을 사용한다.
- RF는 B v4 특징, MiniRocket은 현 2초/30Hz 표현을 사용한다.
- real-only를 공통 기준선으로 두고 합성-only와 실제+증강은 별도 조건으로 비교한다.
- 드론 recall, 새의 드론 오분류율, macro-F1, 보류율, 클래스별 coverage를 보고한다.
- 모델을 고정한 후 GT/A 쌍에서 판정 변화와 점수 차이를 측정한다.
- 회전/크기 정규화나 4초 창 등 표현 변경은 별도 계약 버전 및 재학습을 요구한다.
  학습된 2초 모델에 긴 창을 그대로 넣지 않는다.
- 현재 MiniRocket은 창별 중앙값을 빼고 반경으로 나눈다. 절대 이동 규모의 정보가
  줄어드는 이점/손실, 방향 의존성, 짧은 창의 행동 모호성을 오분류 창과 함께 점검한다.

## 실험 5: 그 다음 확장

- N1/N2로 부족하면 저해상도 GMC + native ROI 측정기를 시도한다.
  원본/처리 좌표 변환과 물리적으로 같은 검색 범위부터 검증한다.
- 원본 패치의 시간 정렬 후 여러 프레임을 이용하는 측정은 저대비 샘플에서 따로 평가한다.
  E5의 재획득 확인 지연과 영상 증거 누적은 다른 실험이다.
- 가림/재등장 데이터가 확보되면 재획득 시간, false reacquisition, ID 유지율을 평가한다.
- 궤적만으로 반복 오분류가 남으면 원본 해상도 외형의 시간 정보를 보조 입력으로 검토한다.
  10px 표적에서 날개짓이나 모터 진동을 복원할 수 있다는 보장은 하지 않는다.
- TransT/MixFormer는 동일 초기 bbox, 처리 시간, GT 조건에서 비교할 독립 후보이며,
  SOT가 전 화면 최초 자동 탐지를 대신하는 것은 아니다.

## 채택 기준

개선 수치의 목표는 신규 실험 전에 고정한다. 관측률을 줄여 위치 점수를 올리는 후보,
위치 오차를 키워 가속도만 맞추는 후보, 특정 객체만 개선하고 나머지에 큰 회귀를 만드는
후보는 채택하지 않는다. 평균과 함께 객체별 회귀 및 실제 기동 구간을 확인한다.
GT 표시 오차 범위보다 작은 변화는 개선으로 단정하지 않는다.

우선 실행 순서는 출처/정책 정리, N1 대조, CMC/GT 진단, 같은 실제 자료 기반 C 비교다.
실제 학습 패키지 확보 전에도 N1과 CMC 진단은 진행할 수 있다.

## 2026-10-17 실행 결과

### A 대비 중심 보정 실험

- N1(보정 OFF): B `acceleration_p95` 상대 오차 절대값 중앙값은
  59.62% 에서 18.97% 로 줄었지만, 6개 모두 위치 P95가 악화했고
  `bird_2` 관측률이 99.34% 에서 93.69% 로 낮아졌다. 미채택.
- N2(보정 반영률 15% -> 5%): `drone_5/6` 떨림은 줄었지만 작은
  새 객체의 위치 P95가 크게 악화했다. 미채택.
- N3(프레임당 보정 0.3px 제한): `drone_6` 떨림 P95는 12.57px 에서
  10.03px 로 줄었지만 새 두 객체의 위치 P95가 3.52 -> 6.87px,
  3.69 -> 5.93px 로 악화했다. 미채택.
- 결론: 대비 보정은 GT 중심 편향을 줄이지만 운동 신호 잡음을
  추가한다. 하나의 전역 강도로는 객체 크기와 배경이 다른 경우를
  동시에 해결하지 못했다. D0 기본값을 유지한다.

### CMC / GT 진단

- `bird_2`, `drone_5`, `drone_6`의 위치 오차와 프레임 간 CMC 변환량
  상관은 0.044, 0.050, 0.045로 매우 작았다.
- CMC 전후 `acceleration_p95` 상대 오차도 각각 52.17/55.79%,
  27.13/27.05%, 45.33/45.52%로 거의 같았다.
- 현재 오차의 우선 원인은 CMC보다 `bird_2`의 motion 의존,
  `drone_5`의 appearance 복구, `drone_6`의 초기 ROI 편향과 appearance
  구간으로 판단한다.
- 산출물: `evaluation/cmc_gt_diagnostics/diagnostics.json`, `report.md`.

### C 공통 데이터와 분류 확인

- D0 공통 GT/A 6개를 `skydetect-common-c-track-dataset-1.0` 후보
  패키지로 구성했다.
- 드론 4개, 새 2개이지만 새 2개가 같은 원본 영상에서 나왔다.
  새의 독립 원본 그룹이 1개라 그룹 단위 train/validation/test는 차단됐다.
- 동일 실제 학습 자료로 RF/MiniRocket을 재학습하는 단계는 원본
  패키지 부재로 미실행이다. 최소 새 원본 그룹 2개를 더 확보해야 한다.
- N1을 기존 배포 모델에 넣은 결과 MiniRocket A는 4/6 -> 3/6,
  RF A는 1/6 -> 0/6으로 악화했다. 단, 이는 모델 알고리즘만의
  공정한 비교가 아니라 기존 배포 구성 재실행이다.

### Holdout 상태

- 미사용 `drone_3` 영상을 보조 holdout으로 선정했다.
- 객체가 약 57~86px로 10~30px 핵심 대역보다 크므로 별도 조건으로만
  보고해야 한다.
- 추적은 실행됐지만 CVAT task 175프레임과 원본 177프레임 불일치로
  평가 안전장치가 채점을 차단했다. 임의 무시하지 않고 데이터 정합성
  보완 항목으로 남겨두었다.
