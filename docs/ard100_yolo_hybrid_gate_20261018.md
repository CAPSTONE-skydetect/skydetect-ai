# ARD100 D0 + YOLO 보수적 하이브리드 실험

## 목적

YOLO가 매 프레임 D0 좌표를 덮어쓰는 방식 대신, D0를 기본 추적기로 유지하면서 신뢰도가 낮거나 궤적이 끊긴 경우에만 YOLO를 보조로 사용할 수 있는지 확인했다. 운영 추적기와 기본 설정은 변경하지 않았다.

## 실험 설계

- 검증 세트: YOLO 학습에 사용하지 않은 원본 영상 11개. 여기서 D0 confidence 문턱 후보 `0.3, 0.4, 0.5, 0.6, 0.7, 0.8`을 비교했다.
- 개발 세트: 고정 영상 12개. 학습과 문턱 선택에서 제외하고, 검증에서 고른 설정을 한 번 적용했다.
- YOLO: 기존 ARD100 학습 모델과 검증에서 정한 detector confidence `0.3988`을 재사용했다.
- YOLO 위치 후보: D0의 현재 위치 또는 최근 두 D0 관측으로 만든 최대 10프레임의 constant-velocity 예측점 주변에서만 탐색했다.
- 채택: detector confidence를 넘고, 인접 프레임 후보와 24 처리 픽셀 이내로 이어지는 경우만 사용했다. 인접 프레임 확인에는 한 프레임의 지연이 필요하다.
- 문턱 선택 기준: 검증 위치 성공률이 D0 대비 1%p 이상 개선되고, 관측률 하락은 2%p 이내이며, 영상별 중앙 오차와 떨림 중앙값이 악화하지 않을 것.
- 평가의 위치 성공률은 GT bbox 대각선의 절반 이내로 계산했다. 추가로 관측률, 중앙 오차, 잔차 변화(떨림), 연속 프레임 비교 비율을 확인했다.

## 결과

검증 11개에서는 여섯 개 confidence 문턱 모두 사전 guardrail을 통과하지 못했다. 점 단위의 저신뢰 D0 좌표를 YOLO 좌표로 바꾸는 것은 채택하지 않고, 점 단위 전환 문턱을 비활성화했다. 따라서 개발 세트의 Hybrid는 D0 관측을 유지하면서, 확인된 누락 구간만 보수적으로 복구한다.

| 개발 세트 지표 | D0 | 기존 YOLO 전 프레임 + gap | D0 유지형 Hybrid |
|---|---:|---:|---:|
| 위치 성공률 | 27.33% | 31.67% | 28.38% |
| 관측률 | 76.99% | 78.18% | 78.18% |
| 영상별 중앙 오차 중앙값 | 111.61 px | 113.52 px | 111.61 px |
| 잔차 변화 중앙값 | 1.158 px | 1.264 px | 1.114 px |
| 연속 프레임 비교 비율 | 81.20% | 82.26% | 82.26% |

Hybrid는 D0 대비 위치 성공률 `+1.05%p`, 관측률 `+1.19%p`, 잔차 변화 중앙값 `-3.8%`였고, 중앙 위치 오차는 같았다. 개발 게이트는 통과했다. Hybrid는 총 43개 누락 프레임을 복구했고, D0가 관측한 점의 좌표를 YOLO로 교체한 수는 0이었다.

이 결과는 기존의 전 프레임 YOLO 전환 방식보다 보수적인 선택이 낫다는 파일럿 근거다. 다만 개선 폭이 작고, 개발 영상 12개에 한정된 결과이므로 운영 채택이나 일반화된 성능 향상을 입증하지 않는다. 특히 높은 D0 confidence가 실제로 낮은 위치 오차를 보장하는지는 별도 검증이 더 필요하다.

## 결론 및 다음 단계

현 단계의 가장 타당한 선택은 YOLO로 정상 D0 좌표를 매 프레임 수정하지 않는 것이다. 확인된 누락 구간에서만 사용하는 보조 탐색은 제한적인 개선 신호를 보였다. 다음에는 이 고정 설정을 새 원본 영상에 적용하고, 누락 복구가 실제 객체를 다시 잡았는지 오버레이로 표본 검수한 뒤 추가 영상으로 동일 지표를 재평가한다. 점 단위 좌표 교체는 새로운 검증 데이터에서 guardrail을 통과하기 전까지 비활성으로 둔다.
